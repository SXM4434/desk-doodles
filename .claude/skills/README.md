# Desk Doodles project skills

Project-scoped skills for Desk Doodles' recurring workflows. Each is a `<name>/SKILL.md` (YAML frontmatter: `name`, `description` + instruction body) that auto-loads when its trigger phrases appear. They bake in the gauntlet ([`../../docs/BUILD-TEST-FLOW.md`](../../docs/BUILD-TEST-FLOW.md)) and the project LAWS.

- **run-audit-sweep** — drive the `/audit` 197-shape catalog across a style/geometry matrix, pixel-analyze headless, build contact sheets, READ them back, flag failures.
- **regression-check** — baseline→change→re-screenshot→diff ritual + the golden-diff gate for classifier/coverage changes.
- **launch-gauntlet-fleet** — scaffold a build+battery+adversarial-verify+smash rock (or laned fleet) with the LAWS block + collision rules baked in.
- **make-checkpoint-prep** — assemble the clean Make-importable file list + importability re-check + ≤10-file upload/routing prompt set.
